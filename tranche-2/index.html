Appendix: scope doc

Direct quotes from the Insight Engine Tranche 2 scope doc, next to the menu item each one supports. Priorities are the scope doc’s.

Chat

Menu item Priority Scope doc
Answers drawn from verified reports, tuned for task briefings Must As a seafarer or supervisor about to start a task, I want to know what has gone wrong during similar work, so that I recognise the critical hazards before I start. … A member of the public asks a task question and receives a briefing in which every claim is cited to a verified report.
Tuned for descriptions of a near miss Must As a seafarer who has just had a near miss, I want to describe what happened, so that I can see whether others have experienced the same thing and what they learned. … A typed description returns related verified incidents, their shared factors and a link to CHIRP’s reporting form.
Every claim cited and checked Must Every claim is cited to source. … Every public answer cites verified records and links to the source report.
Plain maritime English Fixed constraint Outputs are in English only, written in plain maritime English so that users can rely on browser translation.
Toolbox talk format Should As an onboard supervisor, I want the briefing produced as a toolbox talk, so that I can brief the crew from real incidents.
Upload your own document and discuss it Could As an onboard supervisor, I want to upload a draft risk assessment, permit or plan, so that it is challenged against previous incidents before authorisation. … As an organisation or onboard investigator, I want to upload our own report or event narrative, so that I can find comparable cases and lines of enquiry, knowing the document itself is not kept.

Analyst tools and dashboards

Menu item Priority Scope doc
Proposed coding and similar cases for incoming CHIRP reports Must As a CHIRP analyst, I want each report we receive coded and set against similar cases, so that I can assess it quickly and consistently and respond with context. … A submitted report returns proposed coding and similar cases, and nothing enters the database until verified in the review tool.
Pattern finding for CHIRP analysts Must As a CHIRP analyst, I want to ask questions across all reports and datasets, so that I can unearth patterns and publish insight that raises awareness and encourages improvement. … An analyst query returns pathways with supporting cases, and drafting support produces a reviewable outline.
Dashboards Should As a shore-side manager or commercial operator, I want to explore trends across the evidence base, so that I can find vulnerabilities and decide where to invest. … Dashboards filter by vessel type, date, outcome and country, and every figure traces to verified records.

Public launch platform

Menu item Priority Scope doc
Public access kept separate from staff tools Must Logins and role-based access for CHIRP staff and partners; anonymous public access kept separate from the review tool and drafting features.
Rate limits, spending cap, abuse protection Must Rate limiting per user, a spending cap on question-answering costs, and protection against abuse, scraping and prompt injection.
Watching answers, withdrawing an answer or record Must Usage and error monitoring with alerts, and a route to correct or withdraw a published answer or record.

Sources

Menu item Priority Scope doc
Official investigation bodies Must All marine accident investigation bodies publishing in English. Full investigation reports from flag and coastal states. The core corpus.
CHIRP Maritime published reports Must De-identified confidential reports and commentary. Closest to seafarer experience.
MAIB Safety Digests and bulletins Must Short-form learning.
Linking reports that describe the same accident Must Many sources republish or edit the same event (MARS, SAFETY4SEA, IMO GISIS and national bodies). Each derivative account links to its source report, and pattern analysis counts the event once.
IMO GISIS Should Investigation reports submitted to IMO, filling gaps for states without their own publication site.
IMO Lessons Learned Should Short anonymised lessons drawn from member-state investigations.
Nautical Institute MARS Should Free-text narratives of the kind third parties will submit. Mostly edited from regulators’ reports, so depends on duplicate tracking.
SAFETY4SEA Should Incident news and safety articles, often derived from investigation reports, so depends on duplicate tracking.
IMCA safety flashes Should Offshore and marine contracting incidents with lessons.
USCG Marine Safety Alerts Should Short-form alerts linked to US investigations.
Legislation Should UK legislation and MCA notices: instruments to link findings against, starting with the UK flag. ILO Maritime Labour Convention: hours of rest, manning and welfare requirements. IMO conventions and codes: the core international instruments.
Legislation Should As CHIRP, I want to see where incidents recur because regulation is absent, unclear or poorly implemented, so that I can put evidence to flag states and encourage change.
Pre-2005 scanned reports Could Historic depth. Requires OCR, excluded from P1.
P&I club publications Could Claims-led trend analysis and case studies.
Copernicus metocean data Could Historical wind, wave and sea state at the time and position of each incident, enriching reports that omit or understate conditions.
Paris and Tokyo MoU detentions Won’t Deficiency patterns that signal compliance gaps.
Other news and trade press Won’t Fast but secondary, of variable accuracy and under copyright.
Non-English reports via translation Won’t Would widen coverage but conflicts with English-only outputs and adds verification risk.
